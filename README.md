# Exercícios de Python — 1º Semestre (ADS)

Repositório de exercícios práticos em Python desenvolvidos durante o primeiro semestre do curso de Análise e Desenvolvimento de Sistemas. O objetivo deste espaço é registrar a evolução nos fundamentos de programação, lógica e estruturas de dados.

---

## 📁 Estrutura do Repositório

| Pasta | Conteúdo |
| :--- | :--- |
| `01-fundamentos-io/` | Entrada/saída de dados, conversão de tipos e operações aritméticas básicas |
| `02-condicionais/` | Estruturas de decisão (`if`, `elif`, `else`) e condicionais aninhadas |
| `03-lacos-for-while/` | Laços de repetição (`for`, `while`), controle de fluxo (`break`, `continue`) e tratamento de exceções |
| `04-funcoes-estruturas-dados/` | Modularização com funções, manipulação de dicionários e tuplas |
| `05-pygame/` | Game loop, tratamento de eventos, inputs de teclado e colisão com bordas |

> **Nota:** Os scripts da pasta `05-pygame/` (como `quadrado_controlavel.py`) serviram como base conceitual para o desenvolvimento do projeto **Recife Verde**.

---
## 🛠️ Como Executar

1. Certifique-se de ter o Python 3 instalado.
2. Execute qualquer script pelo terminal:

```bash
python3 caminho/do/arquivo.py
```

Os scripts em `05-pygame/` exigem a biblioteca `pygame`:

````bash
pip install pygame
```
